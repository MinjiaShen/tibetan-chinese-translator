## 项目简介

本工具是一款**藏语→中文**实时翻译桌面应用，专注于将藏语内容翻译为中文并以字幕形式展示。支持三种输入方式：语音、键盘、图片OCR，满足不同场景下的翻译需求。

**核心设计理念：**
- 单文件分发，零安装依赖
- 双击即用，自动打开浏览器
- 翻译结果以「藏中对照」字幕形式呈现
- 使用 Google 翻译引擎，藏→中翻译质量最优

**适用场景：**
- 藏语学习者实时理解藏语内容
- 藏区工作、旅游时的即时翻译
- 藏文文献、图片的文字识别与翻译
- 藏语会议、讲座的实时字幕

## 使用指南

### 1. 语音翻译

**操作步骤：**

1. 运行程序后，浏览器自动打开翻译页面
2. 点击页面顶部的 **「🎙️ 语音」** 标签页
3. 点击页面底部的 **🎤 麦克风按钮**
4. 浏览器会弹出麦克风权限请求 → 点击 **「允许」**
5. 开始说藏语
6. 界面实时显示：
   - 识别中的藏文（顶部灰色文本）
   - 翻译完成的中文字幕（主体区域）

**快捷操作：**

| 操作 | 说明 |
|------|------|
| 空格键 | 开始/停止录音 |
| 点击 🎤 | 开始/停止录音 |
| 清空按钮 | 清除所有字幕记录 |

**最佳实践：**

- 在安静环境中使用，减少背景噪音干扰
- 说话清晰，语速适中
- 每句话说完后稍作停顿，等待识别完成
- 使用卫藏方言（拉萨话）效果最佳
- 确保浏览器已获得麦克风权限

### 2. 键盘翻译

**操作步骤：**

1. 点击页面顶部的 **「⌨️ 键盘」** 标签页
2. 在文本框中输入或粘贴藏文
3. 点击 **「翻译」** 按钮（或按 Ctrl+Enter）
4. 翻译结果显示在上方区域

### 3. 图片OCR翻译

**操作步骤：**

1. 点击页面顶部的 **「📷 图片OCR」** 标签页
2. 上传含藏文的图片（两种方式）：
   - 点击上传区域，选择图片文件
   - 直接拖拽图片到上传区域
3. 点击 **「识别并翻译」** 按钮
4. 首次使用会加载 OCR 引擎（约 1MB，需网络）
5. 等待 OCR 识别（通常 10-30 秒）
6. 识别完成后自动翻译并显示结果

### 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|


## 翻译引擎说明

### Google 翻译（唯一引擎）

- **端点：** `translate.googleapis.com`
- **语言对：** 藏语 (bo) → 中文 (zh-CN)
- **费用：** 免费（使用公开端点）
- **质量：** ⭐⭐⭐⭐ 藏→中翻译质量较好
- **超时：** 10 秒自动超时，避免请求挂起
- **限制：** 无明确速率限制，但高频调用可能被临时封禁

### 翻译缓存

- **存储位置：** 浏览器内存（Map 对象）
- **生命周期：** 页面刷新后清空
- **命中条件：** 完全相同的藏文文本
- **效果：** 相同文本秒级返回，不消耗 API 配额

### 翻译优先级

```
1. 缓存命中 → 直接返回（来源: 缓存）
2. Google 翻译 → 成功则返回（来源: Google）
3. 全部失败 → 返回 "[翻译失败] 原文"
```

## 常见问题

### Q: 浏览器没有自动打开怎么办？

**A:** 手动在浏览器中访问程序显示的地址，通常是：
```
http://127.0.0.1:9090
```

### Q: 提示"浏览器不支持语音识别"怎么办？

**A:** 请使用 **Google Chrome** 或 **Microsoft Edge** 浏览器。Safari 和 Firefox 对 Web Speech API 的藏语支持有限。

### Q: 麦克风没有反应怎么办？

**A:** 按以下步骤排查：

1. **检查浏览器权限：** 点击地址栏左侧的锁/麦克风图标，确认已允许
2. **检查系统权限：**
   - Windows: 设置 → 隐私 → 麦克风 → 允许浏览器访问
   - macOS: 系统偏好设置 → 安全性与隐私 → 麦克风 → 勾选浏览器
   - Linux: 确认 PulseAudio 正在运行
3. **检查硬件：** 确认麦克风已连接且未被其他程序占用

### Q: 语音识别不准确怎么办？

**A:**

- 尽量使用**卫藏方言（拉萨话）**，Web Speech API 对它支持最好
- 在安静环境中使用，减少背景噪音
- 说话清晰，语速适中
- 如果识别效果持续不佳，建议使用**键盘输入**方式

### Q: 翻译失败怎么办？

**A:**

- 检查网络连接
- Google 翻译可能被临时限制，稍后重试
- 尝试缩短翻译文本长度
- 使用键盘输入方式手动输入藏文测试

### Q: OCR 识别很慢怎么办？

**A:**

- 首次使用需下载 OCR 引擎（约 1MB），需要网络
- 识别速度取决于图片大小和文字复杂度
- 建议裁剪图片，只保留需要识别的区域
- 清晰的扫描件比手机拍照识别更快更准

### Q: 端口 9090 被占用怎么办？

**A:** 程序会自动尝试 9090-9099 范围内的可用端口，无需手动处理。

### Q: 能否离线使用？

**A:**

- **语音识别**需要网络（Web Speech API 依赖网络）
- **翻译**需要网络（调用 Google API）
- **OCR**首次需要网络下载引擎，之后可离线使用
- 完全离线使用暂不支持

## 已知限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 藏语语音识别准确度 | Web Speech API 对藏语的支持不如中文/英文 | 口音重或环境噪音大时识别率下降 |
| 翻译质量 | Google 翻译藏→中质量有限，复杂句式可能不准确 | 长句或专业术语翻译可能有偏差 |
| 网络依赖 | 所有核心功能需要网络 | 无网络环境无法使用 |
| 浏览器限制 | 语音识别仅支持 Chrome/Edge | Safari/Firefox 用户无法使用语音功能 |
| OCR 引擎大小 | Tesseract.js 引擎约 1MB（延迟加载） | 首次使用需等待下载 |
| 无历史持久化 | 翻译记录不保存到本地 | 刷新页面后记录清空 |
